# Day 16: Semantic Search

## Objective

Retrieve information by meaning rather than exact keywords.

## Hands-On Challenge

Use the local retriever against the knowledge directory.

## What You Should Be Able to Explain

- What problem this capability solves
- Where it belongs in the architecture
- What could fail
- How you would evaluate it
- What would change in production

## Definition of Done

- Complete the hands-on task.
- Run or inspect the associated example.
- Document one failure mode.
- Document one production consideration.
